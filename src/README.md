# MindCare BD - Mental Health Support Platform

A full-stack mental health support application for Bangladeshi students.

## Tech Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express + PostgreSQL
- Authentication: JWT + Bcrypt

## Features
- Anonymous problem submission
- Professional doctor responses
- Mood tracking
- Emergency resources

## Installation

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
